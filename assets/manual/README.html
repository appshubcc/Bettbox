iGame+ 使用说明

写给日常玩游戏的朋友：本软件开箱即用，不用研究复杂选项。

第一步：选择线路

在「当前节点」点击 「节点」选择适合自己的线路；也可以使用默认 「自动选择」。

「自动选择」解释说明：

故障转移策略，默认按顺序选择，当前线路不可用时自动切换下一条线路。

第二步：启动代理

虚拟网卡模式（TUN）：适合玩游戏场景。
  • 系统代理：适合浏览网页场景。
  • 二者一般不必同时开启；按使用场景选一种即可。

第三步：验证代理

开启代理后，查看 「IP 信息」 是否已变为与节点地区一致的出口。

代理模式说明

规则：最常用，国内外自动分流，不影响国内软件使用。
  • 直连：全部流量走本地。

其他问题

连不上、延迟高、打不开网页等，先确认 线路/节点 可连接，并已按上面对应开启 TUN（若玩游戏）。

仍解决不了，请 联系商家 协助解决。
